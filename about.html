About SoundLoop

SoundLoop is a student website project about discovering and enjoying music. It brings together a featured audio player, playlist ideas, genre information, and a way for visitors to send feedback.

Website goals

  • Make music content easy to explore.
  • Provide a simple audio player with visitor-controlled playback.
  • Organize music ideas by playlist and genre.
  • Use clear navigation and a contact form.

Built for exploration

Each page shares the same navigation menu so visitors can move around SoundLoop from any page.
