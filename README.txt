SOUNDLOOP WEBSITE — SOURCE FILES

Included pages:
- index.html: Home page
- listen.html: Audio player page (includes an HTML table)
- about.html: About page
- styles.css: Shared styling
- assets/soundloop.mp3: Featured audio file (upload this file separately if it is not present)

Planning documents:
- table-page-sketch.txt: Wireframe sketch of the page using a table
- site-map.txt: Website navigation map

HOW TO PREVIEW:
1. Keep the folder structure intact.
2. Open index.html in a web browser.
3. Use the navigation links to visit all three pages.

HOW TO PUBLISH:
Upload the contents of this folder to a free website host or website builder.
For a simple static site, GitHub Pages can publish the HTML/CSS files.
