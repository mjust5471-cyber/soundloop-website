# SoundLoop — revised site map

The six main website pages share a navigation menu.

- **Home** — `index.html`
  - Introduction and links to the main sections
- **Listen** — `listen.html`
  - Featured audio player and control guide
- **Playlists** — `playlists.html`
  - Example collections for different moods
- **Genres** — `genres.html`
  - Descriptions of popular music genres
- **About** — `about.html`
  - Project purpose and website goals
- **Contact** — `contact.html`
  - Visitor feedback form

All six pages link to one another through the shared top navigation.
